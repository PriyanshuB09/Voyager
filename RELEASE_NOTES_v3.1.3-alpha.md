# Voyager v3.1.3-alpha

## What's new

- Corrected the reversed **Very low** and **Very high** behavior for both A* planner sliders.
- Flipped the corresponding grid-spacing, corner-rounding, and turn-penalty endpoint mappings together so the two controls remain consistent.

## Downloads

- `Voyager Setup 3.1.3-alpha.exe` — Windows installer
- `Voyager 3.1.3-alpha.exe` — portable Windows application

> These builds are not digitally signed, so Windows SmartScreen may display an **Unknown publisher** warning.
